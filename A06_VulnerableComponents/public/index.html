A06: Уразливі та застарілі компоненти

Мета: Виявити вразливі залежності в Node.js-додатку за допомогою інструментів аналізу!

Цей сайт — фейковий. Але в ньому використовується застаріла версія Express.js, яка має відому вразливість.

Завдання:

  1. Запустіть додаток: npm install && npm start
  2. Перейдіть на http://localhost:3006 — відкриється сторінка.
  3. Перейдіть на http://localhost:3006/api/info — чи бачите ви версію Express?
  4. В консолі виконайте: npm audit — чи ви бачите вразливість?
  5. Знайдіть відповідь на питання: Яка CVE-ідентифікація вразливості?
  6. Як виправити? — Оновіть `express` до версії 4.17.1 або вище.
  7. Після оновлення — знову запустіть npm audit — чи вразливість зникла?

💡 Підказка:

У реальному житті:

  • 80% веб-додатків використовують застарілі бібліотеки.
  • Атакувач може отримати доступ до файлів сервера через Directory Traversal.
  • Ви можете виявити це за допомогою npm audit, snyk, або OWASP Dependency-Check.

Підказка для виявлення вразливості:

npm audit
# Вивід повинен містити:
# High            Directory Traversal
# Package         express
# Patched in      >=4.17.1
# Dependency of   express
# Path            express@4.16.0
# More info       https://npmjs.com/advisories/1087
