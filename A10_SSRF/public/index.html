Server-Side Request Forgery - Підробка серверних запитів

Що таке SSRF?

SSRF (Server-Side Request Forgery) — це вразливість, яка дозволяє атакувачу змусити сервер виконати HTTP-запити до довільних URL. Це може призвести до:

  • Доступу до внутрішніх API та сервісів
  • Витоку секретних ключів з метаданих хмари
  • Сканування внутрішньої мережі
  • Обходу файрволів та ACL

Завдання

  1. Виконай звичайний запит до https://httpbin.org/ip — все працює нормально
  2. Спробуй отримати внутрішній API: http://localhost:3010/internal/api
  3. Витягни базу користувачів: http://127.0.0.1:3010/internal/users
  4. Отримай метадані хмари: http://localhost:3010/metadata/credentials
  5. Зламай адмін-панель: http://127.0.0.1:3010/admin/dashboard
  6. Знайди всі прапорці (flags) у відповідях!

Як це виправити?

  1. Whitelist дозволених доменів — дозволяти тільки безпечні URL
  2. Блокувати приватні IP — заборонити 127.0.0.1, 10.x.x.x, 192.168.x.x тощо
  3. Використовувати бібліотеки — ssrf-agent, validator для перевірки URL
  4. Відключити редіректи — maxRedirects: 0
  5. Network segmentation — ізолювати внутрішні сервіси
