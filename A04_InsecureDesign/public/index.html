Завдання для виконання

Завдання 1: Підбір токена

  1. Використайте email bob@example.com та username bob
  2. Згенерувати токен через "Підбір токена"
  3. Скопіюйте токен та перейдіть: http://localhost:3004/reset?token=ВАШ_ТОКЕН
  4. Змініть пароль адміністратора

Завдання 2: SQL Injection

  1. У полі "Ім'я користувача" введіть: admin' OR '1'='1
  2. Пароль можна ввести будь-який
  3. Клацніть "Увійти" та проаналізуйте результат

Завдання 3: IDOR

  1. Змінюйте User ID від 1 до 2
  2. Переглядайте дані різних користувачів без авторизації

Завдання 4: Аналіз токенів

  1. Натисніть "Завантажити токени"
  2. Проаналізуйте структуру токенів
  3. Спробуйте використати старий токен повторно
